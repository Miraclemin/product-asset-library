从两份 PDF 建产品知识库

准备好已登录的 Codex 桌面版。索引脚本使用 Python 3.9 或更新版本；让 Codex 检查即可。

① 打开项目

先解压，在 Codex 选择本地项目文件夹，打开整个「产品素材库课堂」。Skill 已放在项目的 .agents/skills 目录，学员不用另外找脚本。

② 把来稿交给 Codex

在项目里新开对话，把「01 客户素材」文件夹拖进输入框，发下面的话。里面只有两份 PDF，第一次整理时知识库才会生成。

用 product-asset-library 整理这个素材文件夹。按产品型号建卡，每条资料链接到原文件并标页码。给我一个能打开的知识库首页。

③ 问一个能核对的问题

P25 的点间距是多少？P39 用哪份安装指南？各给我一个可以打开核对的出处。

点开答案里的原件，核对 PDF 第 1 页。再点回知识库首页，看看同一份指南出现在哪两款产品卡上。

④ 模拟客户补资料

把「02 课中补件」里的 PDF 复制到「01 客户素材」，保留前两份原件。在同一对话发送：

客户刚补了 P25-待审第三版.pdf。只读取这份新文件，更新受影响的产品卡。记录它的审核状态，并保留现行版本和依据。

打开 P25 卡：现行规格书仍是 Rev 2，Rev 3 作为待审来稿登记。P39 继续引用原安装指南。

换成自己的素材

如果要跨项目使用，在本项目里告诉 Codex：

把本项目自带的 product-asset-library 安装为我的个人 Skill，保留完整的 scripts 和 references。

安装后新开一个素材整理对话，拖入自己的文件夹。需要上传到 WordPress 时，另行准备可写的练习站和 WP Build。
