首次使用 · 安装 Skill

下载教学包并解压，在 Codex 桌面版打开解压后的项目。

在 Codex 里说

请将项目里的 skills/product-asset-library 安装为我的个人 Codex Skill，保留 scripts 和 references。

安装后新开对话，开始第一步。索引脚本使用 Python 3.9 或更新版本。

第 1 步 / 共 5 步

把整个素材文件夹交给 Codex

把教学包里的 examples/LED-来稿 拖进 Codex 对话框并发送。你自己的素材也可以直接拖整个文件夹。

在 Codex 里说

用 product-asset-library 整理这个文件夹。找出重复图，列出能确认用途的素材，把拿不准的单独列出来。

打开盘点结果

来稿共 4 个文件：上面两张图、一张叫“销售转发.jpg”的副本和一份产品表。副本与 column.jpg 的文件指纹相同，只需选一份上传。stage.jpg 可以归入舞台屏，型号留待补充。

第 2 步 / 共 5 步

FLEX-DEMO 用哪张封面？

在同一对话里按型号提问，点击 Codex 返回的用途索引。

在 Codex 里说

查一下 FLEX-DEMO 的产品封面。告诉我文件名、要放在哪个页面，以及判断依据。

答案是 column.jpg。产品表第 2 行明确指定它是 flex-demo 页面的产品封面。下次再问，Codex 可以直接查这条记录。

第 3 步 / 共 5 步

把确认好的封面挂到草稿

准备一个已连接的本机 WordPress 练习站。WP Build 需要有写入产品草稿、上传媒体和设置特色图片的权限。

在 Codex 里说

生成 FLEX-DEMO 的上传清单。用 WP Build 的 wordpress-content 读取清单，在本机练习站找到 flex-demo 产品草稿；如果没有就新建草稿。将指定图片设为封面并保存。

第 4 步 / 共 5 步

看草稿，也核对附件编号

打开草稿预览，确认页面标题与产品一致，再看封面是不是那张橙色圆柱屏。

在 Codex 里说
