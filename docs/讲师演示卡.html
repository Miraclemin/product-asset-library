课堂演示 · 从两份 PDF 到产品卡

建议 8 分钟。课前先在自己电脑解压学员包，确认 Codex 能访问本地文件、调用 Skill 和 Python 3.9+、读取 PDF；正式演示用新解压的一份，从空库开始。

第 1 分钟　让大家先看原件

投影「01 客户素材」，打开两份 PDF 的第一页。问：“销售现在问 P39 用哪本安装指南，你要去哪里找？”这时屏幕上只有原件。

第 2–4 分钟　当场建库

Codex 打开整个「产品素材库课堂」。拖入「01 客户素材」，复制学员指令卡的第一条话。打开结果首页，再点 P25 和 P39 两张卡。让学员观察：一份安装指南能被两个型号引用。

第 5 分钟　让学员验证答案

P25 点间距多少？P39 用哪份安装指南？把依据点给我看。

核对答案：P25 为 2.5 mm，来自 P25-v2.pdf 第 1 页。安装指南第 1 页写着适用于 P25 和 P39。把产品卡和原件并排展示。

第 6–7 分钟　加入待审来稿

复制「02 课中补件」里的 PDF 到客户素材目录。发学员卡上的更新指令。打开更新后的 P25 卡，指出 Rev 2 是现行版，Rev 3 是待审稿。请学员说出：仅凭版本号为什么不能换掉现用资料？

第 8 分钟　接到 WP Build

有练习站时，说下面这句话；没搭站的课堂直接展示已验证的草稿截图。先点产品卡，指给大家看建站工具要取哪两项内容。

用 WP Build 在我的本机练习站建立或更新 P25 产品草稿。点间距从 P25 产品卡读取，把 installation.pdf 放到安装指南下载区。保存后打开草稿让我核对。
